# Vendored skills

These skills are copied from Matt Pocock's skills repo (https://github.com/mattpocock/skills, MIT license, see `LICENSE-mattpocock-skills`), commit `4ae2317` (2026-10-31).

They live here instead of being installed as a plugin because cloud sessions don't install plugins from project settings automatically, but they always load skills from `.claude/skills/`.

- `wayfinder`: plan a big effort as a map of decision tickets (invoke with `/wayfinder`)
- `grilling`, `domain-modeling`, `research`, `prototype`: skills wayfinder calls while working tickets

To update, copy the newer skill folders from that repo over these.
