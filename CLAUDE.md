# ftbboy2115

This repo is Clay's GitHub profile README plus a home for side projects. Each project lives in its own folder; keep project files out of the repo root.

## Projects

- `marketplace-agent/`: turning Clay's Facebook Marketplace listing agent into a paid service. Start with `marketplace-agent/README.md`.

## Agent skills

Matt Pocock's skills (`mattpocock-skills` plugin) are enabled for this repo in `.claude/settings.json`.

### Issue tracker

Local markdown, per project. For marketplace-agent, wayfinder maps and tickets live in `marketplace-agent/wayfinder/`. See `marketplace-agent/docs/agents/issue-tracker.md`.

### Domain docs

Single-context, per project: `marketplace-agent/GLOSSARY.md` and `marketplace-agent/docs/adr/`. See `marketplace-agent/docs/agents/domain.md`.
